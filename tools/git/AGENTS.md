# Проверка Git-снимков

## Назначение

Проверять именно будущий коммит или отправляемый tip.

## Границы

Без stash/reset/stage пользовательских файлов. Временные каталоги принадлежат .quality; manifest/lock должны соответствовать установленным зависимостям.

## Зависимости

Git blobs → tools/quality/run.mjs. .githooks содержит только shell entrypoints.

## Карта

| Путь                       | Ответственность                                                              |
| -------------------------- | ---------------------------------------------------------------------------- |
| [hooks.mjs](hooks.mjs)     | Материализация индекса/tip, запуск gate, перенос отчёта и безопасная очистка |
| [install.mjs](install.mjs) | Установка исполняемых hooks без замены чужого hooksPath                      |
