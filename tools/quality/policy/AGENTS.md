# Проверки исходников

## Назначение

Чистый анализ AST и текста переданного инвентаря. Вход компонента — `index.mjs`.

## Границы

Не читает диск, не выполняет проверяемый код и не исправляет файлы. Ошибки обязательных правил нельзя закрыть записью ревью.

## Зависимости

Acorn разбирает JavaScript; `node:path` и `node:module` дают нормализацию путей и имена встроенных модулей. Пороговые правила не заменяют проверку поведения.

## Карта

Направления между компонентами задаются в `components.mjs`; неизвестный владелец исходника отклоняется.

| Путь                                 | Ответственность                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------------- |
| [index.mjs](index.mjs)               | Собирает проверки исходников и возвращает детерминированные findings.           |
| [ast.mjs](ast.mjs)                   | Обходит дочерние AST-узлы без выполнения кода.                                  |
| [constants.mjs](constants.mjs)       | Определяет группы AST-форм, тестов и возможностей среды.                        |
| [scopes.mjs](scopes.mjs)             | Различает локальные привязки, параметры и глобальные ссылки.                    |
| [values.mjs](values.mjs)             | Ограниченно вычисляет константы и разрешает цепочки псевдонимов.                |
| [imports.mjs](imports.mjs)           | Проверяет направления зависимостей, циклы и границы generic-компонентов.        |
| [components.mjs](components.mjs)     | Задаёт разрешённые направления между владельцами core, UI и service.            |
| [capabilities.mjs](capabilities.mjs) | Выявляет доступ к среде и динамическому выполнению.                             |
| [test-policy.mjs](test-policy.mjs)   | Обнаруживает исключённые тесты и подмену обязательного native-режима.           |
| [metrics.mjs](metrics.mjs)           | Измеряет сложность и существенные дубли для обязательного ревью.                |
| [text.mjs](text.mjs)                 | Проверяет конфликтные маркеры, пробелы, незавершённые комментарии и подавления. |
