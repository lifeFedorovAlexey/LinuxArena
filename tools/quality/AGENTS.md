# Quality Gate

## Назначение

Объединить проверяемые правила структуры/кода с тестами и точным экспертным ревью.

## Границы

ERROR не снимается записью ревью. Любая недоступная обязательная проверка блокирует gate. Не считать эвристику доказательством корректности.

## Зависимости

policy и structure анализируют данные; inventory читает файлы; run вызывает реальные инструменты. Git hooks и CI используют один runner.

## Карта

| Путь                                 | Ответственность                                                                          |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| [vendor.mjs](vendor.mjs)             | Членство upstream-файлов в закреплённом manifest без исключения новых собственных файлов |
| [run.mjs](run.mjs)                   | Оркестратор fast/full, исходные хеши, проверки и JSON-отчёт                              |
| [inventory.mjs](inventory.mjs)       | Полный список собственных файлов, включая неизвестные расширения                         |
| [structure.mjs](structure.mjs)       | Лимиты, архитектурные карты и владение каждым файлом                                     |
| [reviews.json](reviews.json)         | Обоснование конкретных эвристик с хешами проверенных файлов                              |
| [policy/AGENTS.md](policy/AGENTS.md) | AST-анализ полномочий, зависимостей и сложности                                          |
