# Инструменты разработки

## Назначение

Обеспечивать воспроизводимую сборку, полный запуск тестов и обязательные проверки.

## Границы

Инструменты не становятся зависимостью продукта. Проверка не изменяет индекс или исходники для получения зелёного статуса.

## Зависимости

Node/npm, Git, Rust; команды опубликованы в корневом package.json.

## Карта

| Путь                                   | Ответственность                                |
| -------------------------------------- | ---------------------------------------------- |
| [build.mjs](build.mjs)                 | Копирование клиента и vendor-ресурсов в dist   |
| [test.mjs](test.mjs)                   | Рекурсивное обнаружение и запуск всех test.mjs |
| [git/AGENTS.md](git/AGENTS.md)         | Установка hooks и проверка Git-снимков         |
| [quality/AGENTS.md](quality/AGENTS.md) | Политики, структура, оркестрация gate и отчёт  |
