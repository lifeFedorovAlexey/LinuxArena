# Архитектурные решения

## Назначение

Объяснять, почему выбраны границы и какие инварианты нельзя потерять.

## Границы

Новая структура или полномочия требуют отдельного решения до реализации; ADR не разрешает обход тестов.

## Зависимости

CONCEPT задаёт цель; локальные карты показывают действующую структуру.
