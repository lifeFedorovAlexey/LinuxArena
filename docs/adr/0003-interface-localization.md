# Локализация интерфейса

Дата: 2026-10-22. Статус: принято для реализации, не принятие релиза.

## Решение

Локаль принадлежит UI/shared/i18n. Русский — исходный язык и fallback; браузерный
язык не меняет начальный выбор. Явный выбор RU/EN хранится отдельно от черновиков
в localStorage. Недоступность хранилища не блокирует переключение в текущей вкладке.

Каталоги используют полные русские сообщения как ключи (source-message keys).
Параметры имеют имена в фигурных скобках; перевод не исполняет HTML. Добавление
языка требует каталога и записи в реестре локалей. Статическая разметка отмечена
data-i18n, динамический текст проходит через t. Числа форматируются выбранной
локалью; машинные адреса, ASM, идентификаторы и пользовательский ввод не переводятся.

Переключатель — отдельный компонент UI/shared/language-switcher с единственным
шаблоном, своими стилями и lifecycle. Он получает языки, значение, подпись и callback,
не владеет настройками приложения. shell/app создаёт компонент; shell/language
связывает обновление локали с представлениями. В index.html находится только host.

Blockly локализуется через единственный существующий набор определений: меняются
только подписи, варианты отображения dropdown и подсказки. Значения полей, ID,
соединения, сериализация и undo остаются прежними. Core не импортирует UI и не
получает окружение браузера. Русские диагностические сообщения core/API остаются
исходными данными; известные сообщения переводятся только при отображении,
неизвестные сохраняются дословно.

## Проверка

Проверить RU по умолчанию, сохранение EN, fallback, полноту каталога и параметры,
доступные подписи, точные u64 при форматировании, идентичность сериализации Blockly,
сохранение незавершённых блоков, undo и введённого текста при смене языка.
Обязателен полный npm run quality; смена языка не является сохранением программы.
