# Референс Linux

## Назначение

Хранить закреплённый upstream Linux v6.18.58 с проверяемым происхождением.

## Границы

linux/ — неизменяемая внешняя область; карты AGENTS и форматирование внутрь не добавляются. manifest.json фиксирует Git blob/SHA-256 каждого заимствования.

## Зависимости

core/placement указывает строки алгоритма; gate и тесты проверяют manifest перед использованием.

## Карта

| Путь | Ответственность |
| --- | --- |
| [manifest.json](manifest.json) | Релиз, пути, диапазоны строк и хеши источников |
| [linux/](linux/) | Закреплённые upstream-байты и лицензия; навигация по manifest.json |
