# Rust harness

## Назначение

Разделить проверяемую арифметику и внешний CLI-протокол.

## Границы

Не выполнять пользовательский ASM; сохранять unsigned wrapping/flags и корректные ограничения inline asm.

## Зависимости

lib используется main; входы/выходы CLI согласованы с tests/engine.

## Карта

| Путь               | Ответственность                                     |
| ------------------ | --------------------------------------------------- |
| [lib.rs](lib.rs)   | Фиксированные Rust/ASM реализации и граничные тесты |
| [main.rs](main.rs) | Аргументы CLI, JSON, check и измерение образцов     |
