# Нативная граница

## Назначение

Запускать только собранный engine и возвращать его структурированный результат.

## Границы

Путь бинарника фиксирован внутри проекта; без shell и пользовательского ASM. Недоступный engine возвращает явный unavailable, не успех.

## Зависимости

Node child_process; engine/target/release. Вызывается store через внедряемый runNative.

## Карта

| Путь                     | Ответственность                                                  |
| ------------------------ | ---------------------------------------------------------------- |
| [runner.mjs](runner.mjs) | nativeRunner: timeout, JSON результата и обработка недоступности |
