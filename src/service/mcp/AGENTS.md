# MCP агента

## Назначение

Преобразовывать stdio-инструменты агента в запросы к работающему локальному сервису.

## Границы

Только http loopback, без credentials в URL и без redirect. Не выдаёт чемпионство и не исполняет код кандидата.

## Зависимости

@modelcontextprotocol/sdk и HTTP API; LINUXARENA_URL выбирает локальную арену.

## Карта

| Путь                                       | Ответственность                                     |
| ------------------------------------------ | --------------------------------------------------- |
| [server.mjs](server.mjs)                   | Схемы инструментов, маршрутизация и stdio lifecycle |
| [config.example.json](config.example.json) | Пример подключения своего агента к серверу          |
