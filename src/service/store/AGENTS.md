# Состояние кандидата

## Назначение

Хранить последнюю допустимую программу и последовательно применять изменения с rollback при ошибке.

## Границы

Не принимать некорректную программу вместо рабочей. Старые измерения после рестарта недействительны. Не смешивать результат модели и нативный benchmark.

## Зависимости

core/placement задаёт семантику; ../native выполняет фиксированный harness; HTTP вызывает интерфейс хранилища.

## Карта

| Путь                                       | Ответственность                                                  |
| ------------------------------------------ | ---------------------------------------------------------------- |
| [arena-store.mjs](arena-store.mjs)         | Снимки, подписки, валидация запросов, очередь и атомарная запись |
| [candidate-check.mjs](candidate-check.mjs) | Детерминированная выборка сравнения кандидата с Linux-семантикой |
| [defaults.mjs](defaults.mjs)               | Стартовые входы арены, на которых видно округление               |
