# Локальный сервис

## Назначение

Владеть состоянием арены и внешними эффектами, предоставляя один API браузеру и агенту.

## Границы

Слушать только loopback. Кандидат исполняется в ограниченной модели; его ASM никогда не передаётся нативному процессу. Не импортировать UI.

## Зависимости

HTTP → store → core/placement и native. MCP → HTTP, без перехода по redirect.
