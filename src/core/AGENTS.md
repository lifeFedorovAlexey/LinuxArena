# Чистое ядро

## Назначение

Разделить исполнение ограниченного ASM, визуальную программу и конкретный алгоритм Linux.

## Границы

Без DOM, процессов, сети и файловой системы. Общие machine и visual не импортируют placement. Эффекты кандидата не означают совместимость с ABI или загрузкой ядра.

## Зависимости

placement задаёт диалект, входы и начальное состояние; visual получает привязку явно через adapter. Публичные index открывают компоненты, а не скрывают обход границ.
