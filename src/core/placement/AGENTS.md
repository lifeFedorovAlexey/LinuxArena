# Адрес распаковки Linux

## Назначение

Владеть первым фрагментом startup_64 Linux v6.18.58 и его пользовательским контрактом.

## Границы

Сохранять исходные символы, диапазон строк, начальные регистры и семантику сравнений. Предупреждения об imm32 и неподтверждённом ABI остаются явными. Исходники Linux находятся вне этой папки и не меняются.

## Зависимости

model связывает machine с контрактом; adapter связывает visual с model. UI и сервис используют index и visual. Исторические Linux-черновики мигрирует history.
