# Исторические черновики

## Назначение

Переносить сохранённые схемы предыдущих версий в текущий визуальный язык без потери пользовательской работы.

## Границы

Не ремонтировать намеренно пустые сокеты, не терять ID, координаты и отсоединённые блоки. Миграция не принимает кандидат и не меняет хранилище; исходную запись сохраняет UI.

## Зависимости

Используются общий валидатор visual/schema и преобразования выражений. Старые предметные примитивы принадлежат placement и не добавляются в общий язык.
