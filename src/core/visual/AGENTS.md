# Визуальная программа

## Назначение

Один общий язык вложенных команд, условий и выражений для палитры, редактора и эталона.

## Границы

Не импортировать Linux placement, DOM или сервис. Adapter обязателен: он задаёт имена, регистры и машинный API. Незавершённые сокеты допустимы в черновике, но не в скомпилированном пути.

## Зависимости

schema использует language; compiler использует schema и expressions; import строит блоки из графа через import-expressions. Blockly передаётся явно только регистрации общих расширений.

## Карта

| Путь                                             | Ответственность                                                         |
| ------------------------------------------------ | ----------------------------------------------------------------------- |
| [index.mjs](index.mjs)                           | Публичные преобразования с явным adapter                                |
| [language.mjs](language.mjs)                     | Общие шаблоны блоков, сокетов, палитры и необязательного else           |
| [schema.mjs](schema.mjs)                         | Структура черновика, поля, ID и допустимые формы                        |
| [expressions.mjs](expressions.mjs)               | Арифметические выражения и безопасное распределение временных регистров |
| [compiler.mjs](compiler.mjs)                     | Вложенные команды в ASM, соответствие инструкций блокам                 |
| [import-expressions.mjs](import-expressions.mjs) | Операнды машины в редактируемые выражения                               |
| [import.mjs](import.mjs)                         | Структурирование графа в реальные вложенные ветви                       |
