# Ограниченная машина

## Назначение

Разбирать и исполнять точную арифметику u32/u64 с флагами и переходами вперёд.

## Границы

Не знать символы Linux, визуальные блоки и host API. Не исполнять настоящий кандидат ASM. Значения входов, исходные регистры, выход и диалект передаёт вызывающий компонент.

## Зависимости

ISA независима; grammar использует ISA; граф и эффекты используют grammar; execution объединяет их. Дополнительные legacy-операции предоставляются явно.

## Карта

| Путь                                 | Ответственность                                              |
| ------------------------------------ | ------------------------------------------------------------ |
| [index.mjs](index.mjs)               | Публичный вход машинного компонента                          |

| [grammar.mjs](grammar.mjs)           | Разбор и сериализация ограниченного диалекта, проверка меток |

| [effects.mjs](effects.mjs)           | Потенциальные записи регистров по всем ветвям                |
| [numbers.mjs](numbers.mjs)           | Точные числа, границы разрядности и форматирование           |
