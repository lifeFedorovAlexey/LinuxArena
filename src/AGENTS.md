# Компоненты продукта

## Назначение

Разделить чистые алгоритмы, браузер и владельцев внешних эффектов.

## Границы

UI не читает Node/файловую систему. Core не знает DOM, сеть и процессы. Service не импортирует UI.

## Зависимости

UI → core; service → core. UI и MCP общаются с сервисом через loopback HTTP. Ниже выбирай нужную зону.

## Карта

| Путь                                   | Ответственность                                        |
