# Живой контракт

## Назначение

Показывать входы, независимые результаты кандидата и эталона, примеры и конкретную причину расхождения.

## Границы

Вычисления получать из core/placement. Не пересоздавать форму при обновлении состояния. Неполный или ожидающий компиляции черновик не должен показывать старый успех.

## Зависимости

DOM, публичный core/placement и callbacks оболочки для изменения входов и показа проблемного пути.

## Карта

| Путь                                   | Ответственность                                             |
| -------------------------------------- | ----------------------------------------------------------- |
| [contract-view.mjs](contract-view.mjs) | Состояние формы, события и жизненный цикл компонента        |
| [template.mjs](template.mjs)           | Первичная разметка контракта и примеров                     |
| [render.mjs](render.mjs)               | Обновление результатов и диагностики без пересоздания формы |
| [view.css](view.css)                   | Основная компоновка, входы и результаты                     |
| [cases.css](cases.css)                 | Примеры, ошибки и переход к проблемному блоку               |
| [responsive.css](responsive.css)       | Компоновка контракта на узких экранах                       |
| [sidebar.css](sidebar.css)             | Контракт в боковой колонке и reduced motion                 |
