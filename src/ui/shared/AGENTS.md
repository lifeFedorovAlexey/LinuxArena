# Общие элементы UI

## Назначение

Хранить небольшие средства отображения, общие для компонентов страницы.

## Границы

Не владеть состоянием алгоритма, сетью, Blockly или предметной логикой. Не добавлять сюда код только ради уменьшения соседнего файла.

## Зависимости

DOM браузера. Компоненты импортируют эти функции напрямую; обратных зависимостей нет.
