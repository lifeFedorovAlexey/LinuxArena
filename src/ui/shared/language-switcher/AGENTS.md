# Переключатель языка

## Назначение

Один компонент выбора языка, владеющий собственной разметкой и оформлением.

## Границы

Не хранить локаль, не читать localStorage, не перерисовывать приложение. Получать
языки, выбранное значение и подпись от оболочки; передавать выбор через callback.
Обновлять существующие кнопки без потери фокуса. Не дублировать шаблон в index.html.

## Зависимости

Только DOM переданного контейнера. Создание и связь с i18n принадлежат shell/app.
Стили подключаются через единственную точку входа ui/styles.css.
