# Локализация UI

## Назначение

Переводить интерфейс, сохраняя машинные значения и пользовательский текст.

## Границы

Русский по умолчанию и при неизвестной локали/сообщении. Не переводить ASM, значения
полей или данные черновиков. Каталоги содержат текст, не HTML. Полные русские
сообщения — ключи; параметры в фигурных скобках одинаковы во всех языках.

## Зависимости

Только UI и стандартные браузерные API. Без core, сети и Blockly. Выбор языка
сохраняется независимо от алгоритма; компоненты отвечают за свой повторный рендер.

## Карта

| Путь                               | Ответственность                                                |
| ---------------------------------- | -------------------------------------------------------------- |
| [index.mjs](index.mjs)             | Реестр локалей, выбор языка, fallback и подстановка параметров |
| [dom.mjs](dom.mjs)                 | Перевод отмеченных текстов и атрибутов без замены элементов    |
| [en-shell.mjs](en-shell.mjs)       | Английский перевод оболочки, карты и уведомлений               |
| [en-contract.mjs](en-contract.mjs) | Английский перевод контракта и представления результатов       |
| [en-editor.mjs](en-editor.mjs)     | Английский перевод блоков, черновиков и диагностики            |
