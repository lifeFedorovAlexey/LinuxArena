# Карта слоёв

## Назначение

Показывать граф уровней в 3D с доступными DOM метками и понятными переходами.

## Границы

Получать готовый граф; не владеть алгоритмом или маршрутизацией страницы. Сохранять fallback при недоступном WebGL и освобождать геометрию при смене графа.

## Зависимости

Three.js, DOM и callbacks оболочки для подписей и открытия узлов.

## Карта

| Путь                             | Ответственность                                       |
| -------------------------------- | ----------------------------------------------------- |
| [scene.mjs](scene.mjs)           | Камера, renderer, переходы, анимация и жизненный цикл |
| [geometry.mjs](geometry.mjs)     | Геометрия узлов и связей, DOM метки и материалы       |
| [stage.css](stage.css)           | Сцена, панель масштаба и подписи уровня               |
| [nodes.css](nodes.css)           | Метки узлов, состояние трассы и fallback              |
| [responsive.css](responsive.css) | Адаптация карты слоёв к ширине экрана                 |
