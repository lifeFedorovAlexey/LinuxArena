# Оболочка страницы

## Назначение

Связывать сцену, редактор и контракт с текущим состоянием локального API.

## Границы

Не вычислять семантику инструкций и не менять workspace из рендера оболочки. Сохранять несохранённый текст исходника, фокус входов и локальный черновик при SSE.

## Зависимости

Публичный core/placement, UI компоненты, shared и loopback HTTP/SSE. app — единственная точка композиции.

## Карта

| Путь                                                 | Ответственность                                         |
| ---------------------------------------------------- | ------------------------------------------------------- |
| [app.mjs](app.mjs)                                   | Создание компонентов, общего состояния и подписки SSE   |
| [api.mjs](api.mjs)                                   | JSON HTTP клиент с обработкой ошибок                    |
| [layer-graph.mjs](layer-graph.mjs)                   | Раскладка известных слоёв для сцены                     |
| [render.mjs](render.mjs)                             | Заголовок, навигация и доступность действий             |
| [metrics.mjs](metrics.mjs)                           | Отображение проверок и измерений с их областью действия |
| [inspector.mjs](inspector.mjs)                       | Панель кода и входов без потери введённого текста       |
| [workspace-controller.mjs](workspace-controller.mjs) | Переходы слоёв, принятие состояния и сохранение ASM     |
| [run-controller.mjs](run-controller.mjs)             | Пошаговая трасса, проверки и запрос измерений           |
| [bindings.mjs](bindings.mjs)                         | События статических контролов страницы и клавиатуры     |
| [language.mjs](language.mjs)                         | Переключение языка без перезагрузки и записи программы  |
| [styles/AGENTS.md](styles/AGENTS.md)                 | Стили оболочки и её адаптивная компоновка               |
