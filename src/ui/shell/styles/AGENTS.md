# Стили оболочки

## Назначение

Оформлять окружение сцены и редактора, сохраняя порядок правил из ui/styles.css.

## Границы

Стили Blockly принадлежат editor, контракт — contract, граф — scene. Не менять каскад ради переноса правил: проверять широкую и узкую компоновку.

## Зависимости

CSS переменные shared/base.css и DOM оболочки из index.html.

## Карта

| Путь                             | Ответственность                                 |
| -------------------------------- | ----------------------------------------------- |
| [layout.css](layout.css)         | Верхняя панель, заголовок и навигация страницы  |
| [inspector.css](inspector.css)   | Панель контракта и исходного кода               |
| [metrics.css](metrics.css)       | Карточки проверок и измерений                   |
| [footer.css](footer.css)         | Контрибьюторы и нижняя граница страницы         |
| [feedback.css](feedback.css)     | Toast и диалог подключения агента               |
| [responsive.css](responsive.css) | Адаптация оболочки к ширине экрана              |
| [workbench.css](workbench.css)   | Совместная сетка редактора и бокового контракта |
