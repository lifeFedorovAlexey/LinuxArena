# Интерфейс арены

## Назначение

Показывать слои, редактируемый алгоритм и живой контракт без переноса исполнения в UI.

## Границы

Не импортировать сервис или Node API. Не дублировать семантику core. Сохранять черновики, фокус полей и порядок CSS. Цель размера файла — до 400 строк.

## Зависимости

shell связывает компоненты через callbacks и HTTP API. editor и contract используют публичный core/placement. Общий Blockly template принадлежит core/visual, оформление — editor/appearance.

## Карта

| Путь                                     | Ответственность                                              |
| ---------------------------------------- | ------------------------------------------------------------ |
| [styles.css](styles.css)                 | Единственная точка входа CSS с явным порядком каскада        |
| [shell/AGENTS.md](shell/AGENTS.md)       | Состояние страницы, навигация и связь компонентов            |
| [editor/AGENTS.md](editor/AGENTS.md)     | Blockly workspace, сохранение черновиков и единое оформление |
| [contract/AGENTS.md](contract/AGENTS.md) | Входы, результаты и диагностические примеры контракта        |
| [scene/AGENTS.md](scene/AGENTS.md)       | Пространственная карта слоёв и её переходы                   |
| [shared/AGENTS.md](shared/AGENTS.md)     | Общие DOM helpers, иконки и базовые стили                    |
