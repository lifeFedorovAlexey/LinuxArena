# Git entrypoints

## Назначение

Включать обязательную проверку при commit и push.

## Границы

Только запуск общего механизма; без отдельных обходных политик.

## Зависимости

tools/git/hooks.mjs; устанавливаются через npm ci или hooks:install.

## Карта

| Путь                     | Ответственность                            |
| ------------------------ | ------------------------------------------ |
| [pre-commit](pre-commit) | Статический gate по изолированному индексу |
| [pre-push](pre-push)     | Полный gate по каждому отправляемому tip   |
