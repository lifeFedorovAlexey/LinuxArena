# Сервисные интеграции

## Назначение

Проверять loopback API и MCP через настоящие транспортные соединения.

## Границы

Тестовые порты/состояние изолированы. Мок native в HTTP-тесте не является доказательством нативной арифметики.

## Зависимости

src/service/http, src/service/mcp; отдельные engine tests проверяют настоящий бинарник.

## Карта

| Путь                           | Ответственность                                                       |
| ------------------------------ | --------------------------------------------------------------------- |
| [http.test.mjs](http.test.mjs) | Атомарность, перезапуск, SSE, входы, публичные файлы и запрет доступа |
| [mcp.test.mjs](mcp.test.mjs)   | SDK handshake, инструменты и запрет утечки тела при redirect          |
