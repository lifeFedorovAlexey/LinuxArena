# Проверки компонентов UI

## Назначение

Проверять сохранность пользовательского ввода и корректность отображения состояния после обновлений.

## Границы

Использовать реальные public core API и DOM/Blockly fixtures. Не обращаться к живому сервису или пользовательскому localStorage.

## Зависимости

node:test, Blockly/JSDOM, core/placement и компоненты src/ui.

## Карта

| Путь                                             | Ответственность                                                                 |
| ------------------------------------------------ | ------------------------------------------------------------------------------- |
| [block-editor.test.mjs](block-editor.test.mjs)   | Восстановление черновиков, миграции, конфликты и подтверждение сохранения       |
| [contract-view.test.mjs](contract-view.test.mjs) | Результаты контракта, ошибки, фокус полей и обновления входов                   |
| [scene.test.mjs](scene.test.mjs)                 | Геометрия обоих режимов, взаимодействие и освобождение ресурсов при смене графа |
