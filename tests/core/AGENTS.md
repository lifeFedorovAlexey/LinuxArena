# Проверки чистого ядра

## Назначение

Проверять арифметику, визуальные преобразования и контракт выбранного фрагмента независимо от UI и сервиса.

## Границы

Сохранять проверки реальных краёв u32/u64 и флагов. Успешная модель не доказывает загрузку ядра. Тесты используют закреплённый источник и отдельные числовые оракулы.

## Зависимости

Suites повторяют границы src/core; их запускает рекурсивный tools/test.mjs. Для первичного источника разрешено чтение файлов только внутри теста.
