# Проверки контракта Linux

## Назначение

Проверять пользовательские сценарии выбора адреса и объяснения расхождений с эталоном.

## Границы

Ожидаемый результат всегда относится к Linux, даже после изменения кандидата. Неверный или незавершённый кандидат не сохраняет индикатор успеха.

## Зависимости

Используются placement/story и placement/cases вместе с ограниченной машинной моделью. Браузер и нативный harness не требуются.
