# Проверки визуальной программы

## Назначение

Доказывать сохранение поведения при редактировании, импорте ASM, компиляции и миграции черновиков.

## Границы

Не считать сохранённый черновик с пустыми сокетами готовой программой. Отдельно проверять сохранение временных регистров, carry и отсоединённых блоков.

## Зависимости

Blockly используется в штатном headless-режиме. Независимый adapter не импортирует placement; генератор выражений сравнивает исполнение с отдельным BigInt-оракулом.
