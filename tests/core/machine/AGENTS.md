# Проверки машины

## Назначение

Проверять реальную арифметику закреплённого фрагмента, допустимый ASM и поведение переходов.

## Границы

Неподдерживаемые операции и неинициализированные регистры должны завершаться ошибкой. Нельзя заменять точные числа округлёнными Number или ослаблять проверки источника.

## Зависимости

Используются machine и placement с реальным Linux-диалектом. core.test читает reference относительно собственного пути, а не текущего каталога процесса.
