# Регрессии

## Назначение

Проверять контракты компонентов и их взаимодействие; каталог соответствует владельцу поведения.

## Границы

Не скрывать ошибки, не подменять обязательный native запуск моками. Фикстуры могут изолировать процесс, но доказательство такого теста ограничено его сценарием.

## Зависимости

tools/test.mjs рекурсивно запускает все suites; полный gate требует native engine и не допускает skip.
