# Проверки Quality Gate

## Назначение

Проверяет, что обязательный gate обнаруживает нарушения, а не только принимает исправный проект.

## Границы

Git-сценарии работают в собственных временных репозиториях. Не меняют индекс проекта, пользовательские файлы и защиту удалённых веток.

## Зависимости

Node test/assert, Acorn, локальные модули `tools/quality` и `tools/git`; для интеграционных сценариев нужны Git и установленные инструменты проекта.

## Карта

| Путь                                     | Ответственность                                                                         |
| ---------------------------------------- | --------------------------------------------------------------------------------------- |
| [policy.test.mjs](policy.test.mjs)       | Негативные и положительные случаи AST, границ, исключения тестов и эвристик.            |
| [structure.test.mjs](structure.test.mjs) | Полнота карт, ссылки, размеры файлов, локальный контекст и группировка ответственности. |
| [hooks.test.mjs](hooks.test.mjs)         | Снимок индекса, обработка отказа checker и безопасная уборка.                           |
| [git.test.mjs](git.test.mjs)             | Настоящий commit проходит только для исправного staged-содержимого.                     |
| [inventory.test.mjs](inventory.test.mjs) | Полнота файлов любых форматов, исключения локальных данных и запрет ссылок за границы.  |
