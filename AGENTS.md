# LinuxArena

## Назначение

Арена улучшения алгоритмов Linux. Участник меняет визуальную программу вместе со своим ИИ; сервис проверяет контракт, владелец принимает релиз.

## Границы

Читай только карту нужной ветки, затем её входной модуль. Один шаблон на логический тип блока. Сохраняй точную u32/u64-семантику, исходники Linux и пользовательские черновики.

Перед готовностью запускай `npm run quality`; отсутствие проверки или нерешённое ревью блокирует результат. Не ослабляй gate, не переписывай хеши ревью механически. Не коммить и не публикуй без запроса. Изменение границ требует ADR и проверки связанных контрактов. Только владелец принимает релиз.

## Зависимости

Браузер → локальный HTTP-сервис → чистая модель / фиксированный Rust harness. MCP вызывает тот же HTTP API. Это модель арифметики, не загружаемое ядро. Начинай с нужной дочерней карты, а не со всех исходников.
