# LinuxArena

Игровая арена улучшения алгоритмов ядра Linux человеком и его ИИ-агентом.

[Концепция](CONCEPT.md) · [Карта проекта для агентов](AGENTS.md)

## Запуск

Node.js 22.22.2 или 24.15+ и Rust 1.99+ на x86-64 GNU Windows/Linux:

```sh
npm ci
npm run engine:build
npm run dev
```

Открыть http://127.0.0.1:4173. Три слоя: маршрут загрузки → `startup_64` → адрес распаковки. На нижнем слое — редактор Blockly: перетаскивание, соединение, палитра, смена операций, удаление и отмена. Ветвления представлены вложенными «если / иначе» без стрелок. Блоки превращаются в ASM, правки кода возвращаются в блоки. «Как в Linux» показывает неизменный оригинал, сохраняя своё решение. Рядом — входы и четыре условия с ожидаемым и фактическим выходом; проваленный пример объясняет расхождение. Неполный черновик сохраняется локально, но не подменяет рабочую программу.

Собственный агент подключается командой `npm run mcp` (stdio, при работающем сервере). Пример настройки — [конфигурация MCP](src/service/mcp/config.example.json).

## Устройство блоков

[Визуальный язык](src/core/visual/AGENTS.md) задаёт универсальные блоки, проверяет соединения и переводит модель в код. [Машинная модель](src/core/machine/AGENTS.md) отвечает за грамматику, управление и точную арифметику. [Алгоритм Linux](src/core/placement/AGENTS.md) задаёт входы, контракт и привязки; другие алгоритмы подключают свои адаптеры. [Компоненты UI](src/ui/AGENTS.md) используют единые шаблоны и стили.

Числа сохраняются точно до u64; разрядность операции задаётся явно. Пустое гнездо оставляет черновик незавершённым. Временные регистры вложенных выражений учитываются как дополнительные эффекты: проверка результата ещё не доказывает допустимость этих изменений при загрузке ядра.

## Проверки

```sh
npm run quality
```

Обязательные hooks проверяют будущий коммит и push; CI повторяет полный gate на GNU Linux и Windows. Недоступная проверка блокирует результат. Правила и границы автоматизации: [Quality Gate](docs/QUALITY.md). Отчёт — `.quality/report.json`.

База: Linux **v6.18.58**, реальные строки 315–326 `arch/x86/boot/compressed/head_64.S`; происхождение и хеши — [reference/manifest.json](reference/manifest.json). Оригиналы сохраняются побайтово.

Проверки кандидата относятся к ограниченной модели ASM. Отдельно нативный Rust-перенос сравнивается с адаптированными исходными x86-инструкциями. Замеры — локальный микротест фиксированного переноса, **не загрузка ядра и не рекорд изменённого графа**. Полная сборка/загрузка Linux, приём решений, PR-автоматизация и релизы — следующие этапы.

Кандидат и входы сохраняются в `.arena/`; после перезапуска проверки и замеры требуют нового запуска. `dist/` содержит клиент; для его интерактивных операций необходим локальный сервис.
